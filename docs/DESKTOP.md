# Десктопная версия: один файл без установки Python

Приложение можно упаковать в **один исполняемый файл**. Человек, которому вы его
отправили, дважды кликает по нему — и визуализация открывается в его браузере.
Python, numpy, Flask и PyCharm устанавливать не нужно: всё уже внутри файла.

Как это устроено: файл запускает `desktop.py` — тот же Flask-сервер, что и
`run.py`, но только на `127.0.0.1` (снаружи недоступен) и на случайном
свободном порту, после чего открывает браузер. Симуляция считается на компьютере
того, кто запустил файл; у каждого — своя копия.

## Сборка

```bash
pip install -r requirements-build.txt
```
```bash
python build_desktop.py
```

Результат — в папке `dist/` (папки `build/` и `dist/` в git не попадают):

| ОС | Файл |
|---|---|
| macOS (Apple Silicon) | `LJ_MD-macos-arm64` |
| macOS (Intel) | `LJ_MD-macos-x86_64` |
| Windows | `LJ_MD-windows-AMD64.exe` |
| Linux | `LJ_MD-linux-x86_64` |

Размер — около 15–40 МБ в зависимости от ОС.

**Каждая ОС собирается на самой себе.** PyInstaller не умеет кросс-компиляцию:
файл с Mac не запустится на Windows, а сборка на Mac с M-процессором — на старом
Intel-Mac. Чтобы получить файлы для всех систем, не имея их под рукой,
используйте сборку на GitHub (см. ниже).

## Сборка на GitHub (все ОС сразу)

Workflow `.github/workflows/desktop.yml` собирает файлы для macOS (arm64 и
x86_64), Windows и Linux:

- **вручную** — вкладка *Actions* → *Desktop build* → *Run workflow*;
  готовые файлы — в разделе *Artifacts* внизу страницы запуска;
- **по тегу** — при пуше тега вида `v1.0` файлы автоматически прикрепляются
  к релизу на странице *Releases*:

```bash
git tag v1.0 && git push origin v1.0
```

## Как отправить файл

- Упакуйте файл в **zip**: почта и многие мессенджеры блокируют `.exe` и
  исполняемые файлы без расширения. Удобнее всего дать ссылку на страницу
  *Releases* или на облачный диск.
- Предупредите получателя о первом запуске (ниже) — иначе он решит, что
  файл сломан.

## Первый запуск у получателя

Файл не подписан платным сертификатом разработчика, поэтому система
предупредит один раз:

- **macOS** — «Не удаётся проверить разработчика». Правый клик по файлу →
  **Открыть** → **Открыть**. Если файл пришёл в zip и не запускается вовсе,
  в Терминале: `chmod +x LJ_MD-macos-arm64`.
- **Windows** — синее окно SmartScreen: **Подробнее** →
  **Выполнить в любом случае**.
- **Linux** — `chmod +x LJ_MD-linux-x86_64`, затем запуск из терминала.

Первый запуск занимает несколько секунд: файл распаковывается во временную папку.

## Работа и завершение

- Вместе с браузером открывается **окно консоли** с адресом приложения.
  Если браузер не открылся сам, скопируйте адрес оттуда.
- **Закрыли окно консоли — приложение завершилось.** Вкладка браузера после
  этого перестанет отвечать; её можно просто закрыть.
- Кнопка «⬇ CSV» скачивает историю измерений, как и в обычной версии.
