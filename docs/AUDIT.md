## Критические задачи до защиты

1. **Видимый вклад каждого участника.** Заполнить таблицу участников в
   [ROLES.md](ROLES.md). Каждая роль загружает свои файлы со своего аккаунта
   через отдельные PR в порядке: каркас (тимлид) → core → ViewModel (UI) → View (UI) → интеграция (тимлид).
2. **Слить работу в `main`** через PR (сейчас `main` содержит только initial commit).
3. **Убедиться, что CI зелёный** на всех трёх ОС после первого push.

## Ограничения аудита

Тесты запускались только на macOS (arm64, Python 3.13). Linux, Windows и
Python 3.10 будут проверены CI после push. Интерфейс в браузере вручную в
рамках этого аудита не перепроверялся: проверены веб-маршруты (`tests/test_web.py`).
