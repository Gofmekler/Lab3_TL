# Физическая модель и численные методы

## Приведённые единицы

Все величины безразмерные: σ = ε = m = k<sub>B</sub> = 1.
Для аргона σ = 3.405 Å, ε/k<sub>B</sub> = 119.8 K, m = 39.95 а.е.м.,
единица времени τ = σ√(m/ε) ≈ 2.15 пс. Так T* = 1 соответствует ≈ 120 K.

## Потенциал Леннард-Джонса

U(r) = 4ε [ (σ/r)¹² − (σ/r)⁶ ]

- r⁻¹² — отталкивание электронных оболочек на малых расстояниях;
- r⁻⁶ — дисперсионное (ван-дер-ваальсово) притяжение;
- минимум U = −ε при r<sub>min</sub> = 2<sup>1/6</sup>σ ≈ 1.122σ.

Сила: F(r) = −dU/dr = 24ε/r [ 2(σ/r)¹² − (σ/r)⁶ ].

**Обрезка и сдвиг.** На r > r<sub>c</sub> (обычно 2.5σ) взаимодействие
не учитывается, а потенциал сдвигается на U(r<sub>c</sub>), чтобы энергия
была непрерывной.

## Граничные условия

- **Периодические (PBC)**: ячейка окружена своими копиями, атом, вылетевший
  с одной стороны, входит с другой. Расстояния считаются по ближайшему образу:
  Δx ← Δx − L·round(Δx/L). Требование r<sub>c</sub> ≤ L/2.
- **Отражающие стенки**: упругое отражение — координата отражается
  зеркально, нормальная компонента скорости меняет знак.

## Интегратор Верле (скоростная форма)

v(t+½dt) = v(t) + F(t)/m · dt/2
r(t+dt) = r(t) + v(t+½dt) · dt
v(t+dt) = v(t+½dt) + F(t+dt)/m · dt/2

Схема второго порядка, симплектическая и обратимая во времени: полная
энергия не дрейфует, а колеблется около начального значения. Устойчивый
шаг для LJ — dt ≈ 0.001…0.01.

**Порядок точности.** Локальная ошибка — O(dt³), глобальная — O(dt²):
при уменьшении dt вдвое отклонение полной энергии уменьшается примерно в 4 раза.

## Эталон: колебания пары атомов

Около минимума потенциал гармонический: U ≈ −ε + ½k(r − r<sub>min</sub>)², где
k = U″(r<sub>min</sub>) = 72·2<sup>−1/3</sup> ε/σ² ≈ 57.15. Пара атомов колеблется как
осциллятор с приведённой массой μ = m/2:

T = 2π √(μ/k) ≈ 0.588 τ.

Этот и другие аналитические случаи используются для проверки программы —
см. [VERIFICATION.md](VERIFICATION.md).

## Начальные условия

Атомы ставятся в узлы квадратной (кубической) решётки, скорости — по
распределению Максвелла, затем вычитается скорость центра масс и скорости
масштабируются до точной начальной температуры T<sub>0</sub>.

## Наблюдаемые

- Кинетическая энергия: E<sub>kin</sub> = ½ m Σ v<sub>i</sub>².
- Температура: T = 2E<sub>kin</sub> / N<sub>f</sub>, где N<sub>f</sub> = d(N−1)
  при PBC (импульс центра масс сохраняется) и dN для стенок.
- Давление (теорема вириала): P = [N k<sub>B</sub>T + (1/d) Σ<sub>i<j</sub> r<sub>ij</sub>·F<sub>ij</sub>] / V.
  При малой плотности P → ρT (идеальный газ).
- Функция радиального распределения g(r): отношение числа пар на
  расстоянии r к ожидаемому для идеального газа той же плотности.
  - газ: g(r) ≈ 1 везде, кроме r < σ;
  - жидкость: высокий первый пик у r ≈ σ…1.12σ и затухающие осцилляции;
  - кристалл: острые пики на расстояниях координационных сфер решётки.

## Термостаты

- **Масштабирование скоростей**: v ← v·√(T<sub>0</sub>/T) на каждом шаге.
  Жёстко держит T, но не даёт канонических флуктуаций.
- **Берендсен**: λ² = 1 + (dt/τ)(T<sub>0</sub>/T − 1). Температура
  релаксирует к T<sub>0</sub> экспоненциально с временем τ.

Без термостата моделируется микроканонический ансамбль (NVE): сохраняются
E, N, V; дрейф полной энергии — мера качества интегрирования.

## Что можно исследовать в лабораторной

1. Сохранение энергии в NVE при разных dt (дрейф E на графике и в плитке).
2. Плавление: пресет «Кристалл», затем поднимать целевую T термостата и
   следить за g(r) и E<sub>pot</sub>.
3. Уравнение состояния: P(ρ) при фиксированной T, сравнение с ρT.
4. Обмен энергией: E<sub>kin</sub> ↔ E<sub>pot</sub> при старте с решётки.
